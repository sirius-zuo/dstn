## 3.1) Relevance of the IP protection(s) selected, and relation to background IP

**Patents:** the three protocol-level inventions created under this contract — TEE-attested credential issuance, the Proof-of-Traffic-anchored revocation registry method, and the passkey-gated TEE Holder Agent protocol — are filed as Canadian provisional patent applications (Months 1–3), establishing priority before public demonstration. These are foreground IP: novel processes with no prior public implementation, where an exclusionary right is the appropriate protection.

**Copyrights:** the DSTN application-layer source code — Data Aggregation Service connectors, Aries Issuer Agent integration, Supplier Portal, Admin Dashboard, Passkey Registry, TEE Holder Agent implementation, Verifier Widget, and Verification API — is original software automatically protected on creation under the Canadian Copyright Act. This is foreground IP, well suited to fast-iterating code where value lies in the specific, evolving implementation rather than a fixed mechanical design.

**Trade secrets/Informal IP protection:** the `did:stratos` chain-integration internals, the credential-trigger decision logic, and the TEE issuance pipeline's operational configuration are kept as trade secrets where patenting would require disclosing competitively sensitive implementation detail without a corresponding enforcement benefit.

**Relation to background IP:** the Stratos Dcloud infrastructure (blockchain, storage, compute, database) and the Proof-of-Traffic consensus mechanism are pre-existing Stratos / DEC Foundation background IP, already protected as trade secret/patent-candidate prior to this contract, and are licensed for use by the DSTN application layer rather than newly generated under this Offer. Open standards the foreground IP builds on (W3C VC Data Model, DID Core, AnonCreds, Aries RFCs) are third-party background IP used under open licence (Apache 2.0/royalty-free), not claimed as Offeror IP.
